# Chat App with System Prompt

This is a simple Python chat application that demonstrates the use of system prompts in conversational AI. The app is designed for educational purposes and can be extended for more advanced use cases.

## Features
- Interactive chat interface
- System prompt integration
- Easy to customize and extend

## Requirements
- Python 3.12 or higher
- All dependencies listed in `requirements.txt`

## Setup
1. **Clone the repository**
2. **Create and activate a virtual environment** (optional but recommended):
   ```powershell
   python -m venv env
   .\env\Scripts\Activate.ps1
   ```
3. **Install dependencies:**
   ```powershell
   pip install -r requirements.txt
   ```
4. **Run the application:**
   ```powershell
   python chatappwithsystemprompt.py
   ```

## File Structure
- `chatappwithsystemprompt.py` — Main application file
- `requirements.txt` — Python dependencies
- `env/` — Virtual environment (optional)

## Customization
You can modify the system prompt or extend the chat logic in `chatappwithsystemprompt.py` to suit your needs.
